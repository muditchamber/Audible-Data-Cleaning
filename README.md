# Audible Data Cleaning Project

A data cleaning and standardization project using Microsoft Excel and Power Query Editor to prepare an Audible audiobook dataset for analysis.

## Project Overview

This project focuses on cleaning, transforming, and standardizing an Audible dataset using Power Query Editor in Microsoft Excel.

The workbook contains both raw and cleaned data, making it possible to review the transformations and compare the dataset before and after cleaning.

## Objectives

- Improve data consistency and quality.
- Standardize text, dates, durations, and numerical values.
- Handle multiple authors and narrators.
- Prepare structured data for further analysis.

## Tools & Technologies

- Microsoft Excel
- Power Query Editor

## Data Cleaning & Transformation

The following cleaning operations were performed as part of the project:

| No. | Column | Transformation |
|---|---|---|
| 1 | name | Standardized audiobook titles using consistent title casing. |
| 2 | author | Separated combined author names where multiple authors were listed. |
| 3 | releasedate | Standardized dates to DD-MM-YYYY format. |
| 4 | time | Converted text-based audiobook durations into Excel-recognized duration values. |
| 5 | price | Converted prices to numeric values and identified non-numeric entries. |
| 6 | stars | Converted text-based ratings into numeric values. |
| 7 | narratedby | Split multiple narrator names into separate columns. |
| 8 | releaseinfo | Combined release date and language into a new column in DD-MM-YYYY, Language format. |
| 9 | price | Standardized currency values to two decimal places. |

## Project Workflow

1. Imported the Audible dataset into Power Query Editor.
2. Applied data cleaning and transformation steps.
3. Standardized data types and formats.
4. Prepared the cleaned dataset and loaded it into Excel.
5. Organized the raw and cleaned data in the workbook.
