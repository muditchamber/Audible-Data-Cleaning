# Audible Data Cleaning Project

## Project Overview

This project focuses on cleaning, standardizing, and preparing an Audible dataset for analysis using Microsoft Excel and Power Query Editor.

The Excel workbook contains raw and cleaned data, allowing the transformation process to be reviewed and compared.

## Tools & Technologies

- Microsoft Excel
- Power Query Editor

## Data Cleaning & Transformation

The following tasks are included in this project:

1. Standardized audiobook names using consistent title casing.
2. Separated multiple authors in the author column.
3. Standardized release dates to DD-MM-YYYY format.
4. Converted text-based audiobook durations into Excel-recognized duration values.
5. Converted prices into numeric values and identified non-numeric entries.
6. Converted text-based star ratings into numeric values.
7. Split multiple narrators into separate columns.
8. Combined release date and language into a new releaseinfo column.
9. Standardized currency values to two decimal places.

## Workflow

1. Imported the Audible dataset into Power Query Editor.
2. Applied data cleaning and standardization transformations.
3. Prepared the cleaned dataset for further analysis.
4. Loaded the results into Excel for review.
